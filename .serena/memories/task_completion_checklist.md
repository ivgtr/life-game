# タスク完了時のチェックリスト

## 必須チェック

開発タスク完了後、以下を順番に実行すること：

### 1. コード整形

```bash
npm run format
```

- Prettierでコードを自動整形
- スタイルの一貫性を保つ

### 2. Lintチェック

```bash
npm run lint
```

- ESLintでコード品質をチェック
- 警告・エラーがある場合は修正

### 3. 型チェック

```bash
npm run check
```

- TypeScriptの型エラーを確認
- Svelteコンポーネントの型チェックも含む

### 4. テスト実行

```bash
npm test
```

- 既存テストが通ることを確認
- 新機能には対応するテストを追加

### 5. ビルド確認

```bash
npm run build
```

- 本番ビルドが成功することを確認
- ビルドエラーがないかチェック

## 推奨チェック

### コミット前

- 意味のある変更単位でコミット
- コミットメッセージは明確に（日本語OK）
- 不要なデバッグコードやコンソールログは削除

### プルリクエスト前

- GitHub Actionsのワークフローが通るか確認
- CLAUDE.mdやREADMEの更新が必要か確認

## 重要な注意事項

### ライフゲームロジック関連

- コアロジックの変更時は**必ずユニットテスト**を実行・更新
- パフォーマンスに影響する変更は動作確認

### "癒やし"体験の維持

- UIの変更時は視覚的な確認を実施
- アニメーションは穏やかに保つ
- パフォーマンス低下に注意

### GitHub Pagesデプロイ

- `vite.config.ts`の`base`設定を変更しない
- 静的ファイルパスは相対パスまたはbase考慮
