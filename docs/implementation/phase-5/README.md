## 重要な設計判断

### 1. 音響パラメータ

- **密度 → 音量**: 0-30%
- **活動度 → 周波数**: 200-1000 Hz
- **レベル → 倍音構成**: マクロ(低音)、ミクロ(高音)

### 2. Web Audio API

- `OscillatorNode`: 基本波形生成
- `GainNode`: 音量制御
- 加算合成: 複数の倍音を重ねる

### 3. ユーザー体験

- デフォルトはOFF（うるさくならないように）
- ワンクリックでON/OFF切替

## テスト戦略

### 手動テスト対象

- 各ズームレベルでの音の違い
- 密度・活動度変化による音の変化
- ON/OFF切替の動作

### 自動テスト対象

- `calculateDensity()`: 正しく密度が計算されるか
- `calculateActivity()`: 正しく活動度が計算されるか
- `getHarmonicsForLevel()`: レベルに応じた倍音が返されるか
