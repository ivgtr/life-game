## 重要な設計判断

### 1. 操作マッピング

**マウス**:
- ドラッグ → パン
- ホイール → ズーム（マウス位置中心）
- ダブルクリック → ズームイン

**タッチ**:
- 1本指スワイプ → パン
- 2本指ピンチ → ズーム
- ダブルタップ → ズームイン

**キーボード**:
- 矢印キー → パン
- +/- → ズームイン/アウト
- 0 → リセット
- Space → 再生/一時停止

### 2. スムーズスクロール

慣性スクロールは実装しない（シンプルさを優先）

### 3. ズーム中心

マウスホイールズームは、マウス位置を中心に拡大縮小
