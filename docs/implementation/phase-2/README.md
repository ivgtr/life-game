## 重要な設計判断

### 1. 量子もつれ係数

デフォルト値: `0.1` (10%)
- 高すぎると予測不可能になりすぎる
- 低すぎると量子効果が見えない

### 2. レベル間影響の方向

- **マクロ方向**: 上位レベル（粗い）→ 下位レベル（細かい）
- **ミクロ方向**: 下位レベル（細かい）→ 上位レベル（粗い）
- 両方向の影響を適用することで、有機的な相互作用を実現

### 3. 時間スケールの適用

相対論的時間の歪みを `shouldUpdateThisFrame()` で確率的に実装

## テスト戦略

### ユニットテスト対象

- `applyQuantumInfluence()`: 隣接レベルからの影響が正しく適用されるか
- `applyConwayRules()`: 無限グリッドでのConwayルールが正しく動作するか
- `computeNextGeneration()`: 時間スケールが正しく適用されるか

### 統合テスト対象（Step 2.3.1）

- 複数レベルでの同時シミュレーション
- レベル間の影響伝播
- 量子もつれ係数の調整効果
